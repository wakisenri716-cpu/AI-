# 🏢 AIエージェント オフィス

アメーバピグ風のちびキャラ AI エージェントたちが、**営業部**と**事務部**の 2 つのパチンコホールに分かれて、パチンコを打ちながらタスクをこなす放置系シミュレーションゲームです。

パチンコ台の前に座って打っている間が「作業中」。タスクが終わると台が光って大当たり 🎰 → ドル箱を抱えて景品カウンターへ持っていくと提出完了です。

ビルド不要・依存ライブラリなし。`index.html` をブラウザで開くだけで遊べます。

## 部署

上のタブで部署を切り替えます。見ていない部署も裏で仕事を続けます。

| 部署 | 役割（得意なタスク） | ホールの特徴 |
| --- | --- | --- |
| 💼 営業部 | 📞 インサイドセールス（アポ獲得）／📑 提案担当（提案書）／🤝 フィールドセールス（商談）／💐 カスタマーサクセス（既存フォロー） | 赤いカーペット・ピンクのネオン・赤／オレンジ／ピンクの台 |
| 🗂️ 事務部 | 🧾 経理／📦 総務／🪪 人事／⚖️ 法務 | 青いカーペット・水色のネオン・青／紫／ミントの台 |

## 💬 文で指示する

右上の「文で指示する」に、ふつうの文章で書いて Enter（または「指示する」）。誰に・どの部署で・何を・どのくらいかを読み取ります。

| 書き方の例 | どうなるか |
| --- | --- |
| ハルにC社へアポ電して | 営業部のハルに「C社へアポ電」を依頼（種類：アポ獲得） |
| 事務部で請求書の発行を急ぎでお願い | 事務部に「請求書の発行」を 🔥急ぎ で依頼（先に拾われる） |
| ミクは契約書のチェックをじっくりやって | ミクに法務タスクを難易度 ★★★ で依頼 |
| 営業部にサクラって子を採用して | 営業部に「サクラ」を採用（名前は「〜って子」や「」で指定） |
| ハルの名前をハルトに変えて | 名前を変更 |
| みんなコーヒー休憩して／クロはソファで休んで | 休憩に行かせる（作業中なら区切りで中断し、あとで再開） |

- 「。」や改行、「あと、」で区切れば、複数の指示をまとめて出せます
- 部署を書かなくても、内容（請求・契約・商談・アポ…）から部署と種類を推測します
- 難易度：「簡単に・サクッと」→★、「じっくり・丁寧に」→★★★
- 文の読み取りはブラウザ内のルールで行っていて、外部の AI には送っていません

## あそびかた

1. 右側の「タスクを依頼」からお題・種類・難易度・担当を選んで依頼（表示中の部署に届きます）
2. 手の空いたエージェントがタスクを拾い、自分の持ち台に座ってパチンコを打つ（＝作業中。台のランプと液晶が回る）
3. 進捗バーが満タンになると大当たり！ドル箱を「景品カウンター」へ運んで提出
4. 完了ログをタップすると成果物（商談メモ、提案書の骨子、経理処理の結果など）が読めます
5. 「＋採用」で表示中の部署にエージェントを追加。名前は自分で決められます（各部署デスク 6 席まで）

「自動でタスク発生」をオンにしておけば、両部署に依頼が勝手に届くので眺めているだけでも楽しめます。

## エージェントの行動

| 状態 | 内容 |
| --- | --- |
| 🎰 作業 | 持ち台でパチンコを打つ。得意分野（役割と同じ種類）のタスクは 1.6 倍速、レベルが上がるほど速くなる |
| ☕ ドリンク休憩 | 元気が減ると自販機へ。元気 +65 |
| 🛋️ ひと休み | 暇なときはソファでごろごろ（元気が少しずつ回復） |
| 💬 おしゃべり | 暇な仲間のところへ歩いていって雑談 |
| 🎉 大当たり | 完成したらドル箱を景品カウンターへ持っていく |

## キャラクターの着せかえ

キャラクター（またはエージェント一覧のカード）をタップすると、プロフィール画面が開きます。

- 名前（8 文字まで・全部署で重複不可）と役割（部署内の 4 つの役割）の変更
- 髪型 6 種、髪色、服の色、肌の色
- アクセサリー（アンテナ・ヘッドホン・メガネ・リボン・ネコミミ）とその色

## そのほか

- 右上で速度変更（一時停止 / 1倍 / 2倍 / 4倍）
- ホールには景品棚・両替機・自販機・新装開店の花輪・休憩ソファ、奥にもう 1 列の空き台
- 壁の「本日の出玉」ボードと「大当たり王」はリアルタイム更新
- 進行状況はブラウザ（localStorage）に自動保存。↺ ボタンで最初から
