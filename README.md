# 🏢 AIエージェント オフィス

アメーバピグ風のちびキャラ AI エージェントたちが、**営業部**と**事務部**の 2 つのオフィスに分かれてタスクをこなす放置系シミュレーションゲームです。

ビルド不要・依存ライブラリなし。`index.html` をブラウザで開くだけで遊べます。

## 部署

上のタブで部署を切り替えます。見ていない部署も裏で仕事を続けます。

| 部署 | 役割（得意なタスク） | オフィスの特徴 |
| --- | --- | --- |
| 💼 営業部 | 📞 インサイドセールス（アポ獲得）／📑 提案担当（提案書）／🤝 フィールドセールス（商談）／💐 カスタマーサクセス（既存フォロー） | 木の床、トロフィー棚、受注件数ボード、卓上電話 |
| 🗂️ 事務部 | 🧾 経理／📦 総務／🪪 人事／⚖️ 法務 | ブルーグレーの床、書庫キャビネット、コピー機、書類とバインダー |

## あそびかた

1. 右側の「タスクを依頼」からお題・種類・難易度・担当を選んで依頼（表示中の部署に届きます）
2. 手の空いたエージェントがタスクを拾い、自分のデスクへ歩いて作業開始
3. 進捗バーが満タンになると「報告BOX」（営業部）／「書類トレー」（事務部）へ提出
4. 完了ログをタップすると成果物（商談メモ、提案書の骨子、経理処理の結果など）が読めます
5. 「＋採用」で表示中の部署にエージェントを追加（各部署デスク 6 席まで）

「自動でタスク発生」をオンにしておけば、両部署に依頼が勝手に届くので眺めているだけでも楽しめます。

## エージェントの行動

| 状態 | 内容 |
| --- | --- |
| 💻 作業 | デスクで作業。得意分野（役割と同じ種類）のタスクは 1.6 倍速、レベルが上がるほど速くなる |
| ☕ コーヒー休憩 | 元気が減るとコーヒーメーカーへ。元気 +65 |
| 🛋️ ひと休み | 暇なときはソファでごろごろ（元気が少しずつ回復） |
| 💬 おしゃべり | 暇な仲間のところへ歩いていって雑談 |
| 📦 提出 | 完成したら報告BOX／書類トレーへ持っていく |

## キャラクターの着せかえ

キャラクター（またはエージェント一覧のカード）をタップすると、プロフィール画面が開きます。

- 名前・役割（部署内の 4 つの役割）の変更
- 髪型 6 種、髪色、服の色、肌の色
- アクセサリー（アンテナ・ヘッドホン・メガネ・リボン・ネコミミ）とその色

## そのほか

- 右上で速度変更（一時停止 / 1倍 / 2倍 / 4倍）
- 時間が進むと窓の外が夕焼け → 夜空に変化
- 壁の TASK BOARD と MVP ボードは状況に合わせてリアルタイム更新
- 進行状況はブラウザ（localStorage）に自動保存。↺ ボタンで最初から

## ファイル構成

```
index.html  画面の骨組み
style.css   見た目・アニメーション
game.js     部屋/キャラの SVG 描画、経路探索、エージェントの行動ロジック
```
