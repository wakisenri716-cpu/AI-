# 🏢 AIエージェント オフィス

スーツ姿の AI エージェントたちが、**営業部**と**事務部**の 2 つのパチンコホールに分かれて、パチンコを打ちながらタスクをこなす放置系シミュレーションゲームです。

パチンコ台の前に座って打っている間が「作業中」。タスクが終わると台が光って大当たり → ドル箱を抱えて景品カウンターへ持っていくと提出完了です。

ビルド不要・依存ライブラリなし。`index.html` をブラウザで開くだけで遊べます。

## 部署

上のタブで部署を切り替えます。見ていない部署も裏で仕事を続けます。

| 部署 | 役割（得意なタスク） | ホールの特徴 |
| --- | --- | --- |
| 営業部 | インサイドセールス（アポ獲得）／提案担当（提案書）／フィールドセールス（商談）／カスタマーサクセス（既存フォロー） | ワインレッドのカーペット・赤いネオン |
| 事務部 | 経理／総務／人事／法務 | ネイビーのカーペット・青いネオン |

## Claude 連携

> **現在は停止中です。** `game.js` の `CLAUDE_ENABLED` を `true` にし、公開ページで `sample` 機能を宣言し直すと再開できます。停止中はルールベースの解釈と定型文の成果物で動き、添付ファイルはタスクに付くだけになります。

claude.ai で公開したページ（アーティファクト）として開くと、ページの中で Claude が動きます。最初に使うときに、Claude の利用を許可するか確認が出ます（使った分は開いた人の Claude の利用枠から使われます）。

- **文での指示**：Claude が文章を読んで、タスク依頼・採用・名前変更・休憩の操作に変換します。どんな言い回しでも、担当者・部署・種類・難易度・急ぎを判断します。
- **成果物**：完了ログの項目を開くと、Claude がその業務の成果物（提案書の骨子、架電結果、契約書の指摘事項など）を実際に書きます。書いている途中から表示され、「止める」「書き直させる」も使えます。一度書いた成果物は保存されます。

`index.html` をそのままブラウザで開いた場合など、Claude が使えない環境では、下のルールベースの解釈と定型文の成果物で動きます（「文で指示する」の右上に接続状態が出ます）。

## ファイルの添付

「文で指示する」には、ファイルを付けて指示できます。「ファイルを添付」ボタン、入力欄への貼り付け（Ctrl+V / ⌘V、画像のコピーにも対応）、欄へのドラッグ＆ドロップのどれでも添付できます（1回 5 件まで）。

| 形式 | 扱い |
| --- | --- |
| テキスト・CSV・Markdown・JSON など | 中身をそのまま読みます（1ファイル 2 万字まで） |
| PDF | 文字を抜き出して読みます（スキャン画像だけの PDF は画像として添付してください） |
| 画像（JPEG・PNG・WebP・GIF） | 縮小して保持し、Claude が画像そのものを見ます |

- 添付は、その指示から作られたタスクに付きます。複数のタスクを頼んだときは、Claude がどのファイルをどのタスクに使うか振り分けます。
- 成果物を書くとき、Claude は添付資料の内容をもとに書き、資料にないことは「要確認」とします。
- Word・Excel は読み取れません。PDF か CSV に書き出して添付してください。
- 添付はブラウザに保存されます。容量が足りないときは画像だけ外して保存します。

## 文で指示する

右上の「文で指示する」に、ふつうの文章で書いて Enter（または「指示する」）。誰に・どの部署で・何を・どのくらいかを読み取ります。

| 書き方の例 | どうなるか |
| --- | --- |
| 佐藤にC社へアポ電して | 営業部の佐藤に「C社へアポ電」を依頼（種類：アポ獲得） |
| 事務部で請求書の発行を急ぎでお願い | 事務部に「請求書の発行」を 🔥急ぎ で依頼（先に拾われる） |
| 伊藤は契約書のチェックをじっくりやって | 伊藤に法務タスクを難易度 ★★★ で依頼 |
| 営業部に中島という人を採用して | 営業部に「中島」を採用（名前は「〜という人」「〜って人」や「」で指定） |
| 佐藤の名前を佐々木に変えて | 名前を変更 |
| みんなコーヒー休憩して／田中はソファで休んで | 休憩に行かせる（作業中なら区切りで中断し、あとで再開） |

- 「。」や改行、「あと、」で区切れば、複数の指示をまとめて出せます
- 部署を書かなくても、内容（請求・契約・商談・アポ…）から部署と種類を推測します
- 難易度：「簡単に・サクッと」→★、「じっくり・丁寧に」→★★★
- Claude が使えないときは、この表のような言い回しをブラウザ内のルールで読み取ります

## あそびかた

1. 右側の「タスクを依頼」からお題・種類・難易度・担当を選んで依頼（表示中の部署に届きます）
2. 手の空いたエージェントがタスクを拾い、自分の持ち台に座ってパチンコを打つ（＝作業中。台のランプと液晶が回る）
3. 進捗バーが満タンになると大当たり！ドル箱を「景品カウンター」へ運んで提出
4. 完了ログをタップすると成果物（商談メモ、提案書の骨子、経理処理の結果など）が読めます
5. 「＋採用」で表示中の部署にエージェントを追加。名前は自分で決められます（各部署デスク 6 席まで）

「自動でタスク発生」をオンにしておけば、両部署に依頼が勝手に届くので眺めているだけでも楽しめます。

## エージェントの行動

| 状態 | 内容 |
| --- | --- |
| 作業 | 持ち台でパチンコを打つ。得意分野（役割と同じ種類）のタスクは 1.6 倍速、レベルが上がるほど速くなる |
| ドリンク休憩 | 元気が減ると自販機へ。元気 +65 |
| ひと休み | 暇なときはソファでごろごろ（元気が少しずつ回復） |
| 会話 | 暇な仲間のところへ歩いていって雑談 |
| 大当たり | 完成したらドル箱を景品カウンターへ持っていく |

## 外見の設定

人物（またはエージェント一覧のカード）をクリックすると、詳細画面が開きます。

- 名前（8 文字まで・全部署で重複不可）と役割（部署内の 4 つの役割）の変更
- 髪型 6 種（ショート・ロング・ボブ・ポニーテール・短髪・まとめ髪）、髪色、スーツの色、肌の色
- 小物（メガネ・ヘッドセット・キャップ・マスク・ひげ）とネクタイの色（白はノーネクタイ）

## そのほか

- 右上で速度変更（一時停止 / 1倍 / 2倍 / 4倍）
- ホールには景品棚・両替機・自販機・新装開店の花輪・休憩ソファ、奥にもう 1 列の空き台
- 壁の「本日の出玉」ボードと「大当たり王」はリアルタイム更新
- 進行状況はブラウザ（localStorage）に自動保存。↺ ボタンで最初から
